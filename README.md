# Mahmudur Rahman - Portfolio Website

A clean, responsive, high-performance personal portfolio and developer showcase website built with modern HTML5, CSS3, and vanilla JavaScript.

## ✨ Features

- **Responsive & Mobile-First**: Flawlessly adapts to desktop, tablet, and mobile screens.
- **Dark / Light Theme Toggle**: Persistent theme state with smooth transitions.
- **Interactive Typing Effect**: Engaging headline animation in the hero section.
- **Featured Projects**: Showcase cards linked directly to GitHub repositories.
- **Animated Statistics**: Counter animations as you scroll into view.
- **Working Contact Section**: Interactive form with feedback states.
- **Zero Build Setup**: Works out of the box with any static host (GitHub Pages, Vercel, Netlify).

## 🚀 Live Demo & Deployment

### Enable GitHub Pages
1. Go to your repository on GitHub: `Settings` > `Pages`.
2. Under **Build and deployment** > **Branch**, select `main` branch and `/ (root)`.
3. Click **Save**. Your site will be live at `https://mahmudurrahman420.github.io/portfolio-website/`!

## 🛠️ Local Development

Simply open `index.html` in your web browser or run a simple local web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```

Then visit `http://localhost:8000`.
